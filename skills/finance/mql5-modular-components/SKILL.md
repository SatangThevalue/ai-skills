# MQL5 Modular Components

สกิลนี้อธิบายชิ้นส่วน (Modules) ของโค้ด MQL5 ที่ถูกแยกย่อยออกมาจากระบบ Full Loop เพื่อให้ผู้ใช้สามารถนำไปประยุกต์ใช้ประกอบร่าง (Plug and Play) หรือพัฒนา EA ตัวใหม่ๆ ได้ง่ายขึ้น โดยแต่ละไฟล์จะทำงานเฉพาะหน้าที่ของตัวเอง

## When to Use

- "ช่วยแตกแยกย่อย เป็นแต่ละตัวด้วยได้ไหม เพื่ออนาคตจะได้นำไปใช้งานแบบแยกส่วนได้"
- เมื่อผู้ใช้ต้องการเฉพาะฟังก์ชันจัดการออเดอร์ (เช่น Trailing Stop หรือ Grid) ไปใส่ในบอทที่มีอยู่แล้ว
- เมื่อต้องการสร้าง Utility EA สำหรับเฝ้าพอร์ต

## The Modules (อยู่ใน GitHub)

ชิ้นส่วนทั้งหมดถูกอัปโหลดไว้ใน GitHub Repository: `mql5-expert-advisors` โดยแบ่งเป็น 3 ไฟล์ดังนี้:

### 1. `Mod_RiskProtector.mq5` (โล่ป้องกันพอร์ต)
โมดูลนี้ทำหน้าที่เป็น "ผู้คุมกฎ" ทำงานแยกจากตัวยิงออเดอร์ เหมาะสำหรับเอาไปทำเป็น Utility EA เปิดทิ้งไว้เพื่อเฝ้าพอร์ต (แม้จะเทรดมือก็ตาม):
- **Daily Drawdown Limiter:** คำนวณ `% Equity` ที่ลดลงจากตอนเช้า ถ้าติดลบถึงเกณฑ์ จะตัดทุกออเดอร์ทิ้งทันที
- **Friday Close:** สั่งปิดพอร์ตล้างสถานะทั้งหมดในเย็นวันศุกร์ หนี Gap ข้ามสัปดาห์
- **Break-Even System:** ถ้าไม้นั้นทำกำไรไปถึงระดับนึง (เช่น 15 pips) โมดูลนี้จะวิ่งไปแก้ Stop Loss มาขวางหน้าทุนให้โดยอัตโนมัติ

### 2. `Mod_NewsFilter.mq5` (ระบบหลบข่าว)
ไม่ต้องต่อ API ปฏิทินข่าวให้ยุ่งยาก โมดูลนี้ใช้การคำนวณจากกราฟโดยตรง (Volatility Breakout):
- **ATR Spike Detection:** ดึงค่า ATR เฉลี่ย 14 แท่ง มาเทียบกับความยาวของแท่งเทียนปัจจุบัน
- **Action:** ถ้าแท่งเทียนยาวกว่า ATR * 3.0 เท่า (แปลว่ามีข่าวกระชาก) ระบบจะขึ้นป้าย `PAUSED` และส่งสัญญาณบอกให้โมดูลอื่นหยุดยิงออเดอร์เป็นเวลา 30 นาที

### 3. `Mod_GridRecovery.mq5` (ระบบแก้พอร์ต)
นี่คือระบบ Selective Grid สำหรับคนที่อยากเขียนบอทสายแก้ทาง (แบบ Scalping Robot Pro) 
- **Averaging Logic:** คำนวณราคาเฉลี่ย (Average Price) ของทุกไม้ที่ติดลบอยู่
- **Selective Entry:** ไม่ใช่ว่าห่าง 30 pips แล้วจะยิงไม้แก้เลย แต่มันจะรอให้ค่า RSI ยืนยันการกลับตัว (Oversold/Overbought) อีกครั้ง ถึงจะยอมเปิดไม้ต่อไป (ฉลาดกว่าตีกริดธรรมดา)
- **Group Close:** เมื่อกราฟย่อกลับมาทำกำไรหักลบกลบหนี้ถึงระยะ `TakeProfitPips` ระบบจะดึงปลั๊กปิดออเดอร์ชุดนั้นรวบยอดทั้งหมด

## Integration Guide

หากต้องการสร้าง EA ตัวใหม่แบบ Full Loop คุณสามารถก๊อปปี้โครงสร้างจาก `Mod_NewsFilter` ไปใส่ในส่วนบนสุดของ `OnTick()` เพื่อเป็นด่านแรก (Filter) จากนั้นใช้ลอจิกจาก `Mod_GridRecovery` มาจัดการออเดอร์ในด่านที่สอง และปิดท้ายด้วยการเรียกใช้ฟังก์ชันจาก `Mod_RiskProtector` เพื่อควบคุมความเสี่ยง
