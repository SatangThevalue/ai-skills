# กลยุทธ์การเทรด DW (Derivative Warrants) ตลาดหุ้นไทย

คู่มือกลยุทธ์ ข้อควรระวัง และแนวคิดสำคัญสำหรับการเทรด DW ในกระดาน SET สกิลนี้ไม่ได้ออกแบบมาให้ทำงานเป็นสคริปต์ (No Executable Code) แต่เป็นความรู้ที่บอทและผู้ใช้งานควรนำไปพิจารณาก่อนวาง Trading Logic ในระบบอัตโนมัติ

## When to Use
- เมื่อผู้ใช้สอบถามเรื่องความเสี่ยง หรือกลยุทธ์การเทรด DW
- เมื่อบอทจำเป็นต้องสร้างเงื่อนไข Take Profit / Stop Loss ในระบบเทรด DW
- เมื่อต้องการทำความเข้าใจโครงสร้างราคา Gearing และ Time Decay

## Prerequisites
- ทราบชื่อหุ้นอ้างอิง (Underlying Asset) 
- มีข้อมูลตารางราคาจากผู้ออก DW (เช่น DW13, DW01)

## Quick Reference
- **Call (C):** เก็งกำไรขาขึ้น (หุ้นแม่ขึ้น DW ขึ้น)
- **Put (P):** เก็งกำไรขาลง (หุ้นแม่ลง DW ขึ้น)
- **ราคา DW:** Intrinsic Value + Time Value
- **Tick / Effective Gearing:** อัตราทด หากหุ้นแม่ขยับ 1% หรือ 1 ช่อง DW จะขยับกี่ช่อง/กี่ %

## กลยุทธ์และพารามิเตอร์ในการคำนวณ (Strategy & Metrics)

1. **Effective Gearing (อัตราทด):**
   - คือ % การเปลี่ยนแปลงของราคา DW เมื่อหุ้นอ้างอิงเปลี่ยนไป 1%
   - *สูตรคำนวณอัตราทด Tick (โดยประมาณ):* หาก Gearing = 5, เมื่อหุ้นแม่ขึ้น 1% DW จะขึ้น 5%
   - **กลยุทธ์:** สายเก็งกำไรระยะสั้นชอบ DW ออกใหม่ เพราะมี Tick น่าสนใจ แต่ถ้าผิดทาง อัตราทดสูงจะทำให้ "ขาดทุนสูง" ทันที

2. **Time Decay (การเสื่อมค่าทางเวลา):**
   - มูลค่าของ DW จะลดลงเรื่อยๆ เมื่อเข้าใกล้วันหมดอายุ
   - แม้ราคาหุ้นแม่ *ไม่ขยับเลย* แต่ราคา DW ก็จะตกลงจาก Time Decay
   - **กลยุทธ์สำหรับมือใหม่:** ให้เลือก DW ที่มีอายุคงเหลือ **มากกว่า 1 เดือนขึ้นไป** เพื่อลดผลกระทบของการเสื่อมราคา 

3. **การอ่านสัญลักษณ์ (Symbol Syntax):**
   - `ADVANC13C2407A`: หุ้นอ้างอิง (ADVANC), ผู้ออก (13), ประเภท (C=Call), ปี/เดือนหมดอายุ (24/07), รุ่น (A)

## ข้อควรระวัง (Pitfalls & Risk Management)

- **ดูกราฟหุ้นแม่ (Underlying) เสมอ:** ห้ามใช้ Indicator (RSI, MACD, EMA) กับ "กราฟของ DW" เด็ดขาด ต้องวิเคราะห์จาก "กราฟของหุ้นอ้างอิง" เท่านั้น
- **ห้ามถัวเฉลี่ยขาลง (Averaging Down):** เมื่อซื้อ DW แล้วผิดทาง ห้ามซื้อเพิ่มเพื่อลดต้นทุนเฉลี่ย เพราะมี Time Decay เข้ามากดดันด้วย จะทำให้ขาดทุนทวีคูณ
- **Stop Loss ต้องเด็ดขาด:** ต้องมีวินัยตัดขาดทุนตามกรอบเวลา (Time-based Stop Loss) และกรอบราคา (Price-based Stop Loss)
- **ห้ามซื้อ Call และ Put พร้อมกัน (Hedging):** เป็นกลยุทธ์ที่ล้มเหลวในการปฏิบัติจริง เพราะจะโดน Time Decay และส่วนต่างราคาเสนอซื้อ-เสนอขาย (Bid-Offer Spread) กินทุนจนหมด
- **ไม่ต้องคำนวณราคาเอง 100%:** อัตราทดเปลี่ยนแปลงตลอดเวลาตามค่า Delta ให้ใช้ "ตารางราคา DW" ของโบรกเกอร์ผู้ออก (Issuer) เป็นเกณฑ์ในการวางแผน Exit เสมอ
