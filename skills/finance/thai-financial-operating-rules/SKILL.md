# Thai Financial Operating Rules
> "รักษาเงินต้นให้รอด ก่อนคิดถึงกำไรเสมอ" — ton-crassula

กฎชุดนี้ใช้เป็น baseline สำหรับการตัดสินใจทางการเงินทุกข้อ
ลำดับความสำคัญ: ภาษี > ฉุกเฉิน > หนี้ > ลงทุน > เก็งกำไร

---

## 1. ภาษีเงินได้บุคคลธรรมดา (PIT)

### Residency Rule
- อยู่ไทย >= 180 วัน/ปีปฏิทิน = "ผู้มีถิ่นที่อยู่" -> เสียภาษีบนรายได้ทั่วโลกที่นำเข้าไทย
- อยู่ < 180 วัน = เสียเฉพาะรายได้แหล่งไทย
- ป.161/2566: เงินต่างประเทศที่นำเข้าไทย **ในปีเดียวกับที่ได้มา** -> ต้องยื่นภาษี

### Brackets (Net Income หลังหักค่าใช้จ่ายและลดหย่อน)
```
0 - 150,000       = 0%   (ยกเว้น)
150,001 - 300,000 = 5%
300,001 - 500,000 = 10%
500,001 - 750,000 = 15%
750,001 - 1,000,000 = 20%
1,000,001 - 2,000,000 = 25%
2,000,001 - 5,000,000 = 30%
> 5,000,000       = 35%
```

### ลดหย่อนมาตรฐาน
| รายการ | วงเงิน |
|--------|--------|
| ส่วนตัว | 60,000 |
| คู่สมรส (ไม่มีรายได้) | 60,000 |
| บุตรคนแรก | 30,000 |
| บุตรคนที่ 2+ (เกิด >= 2018) | 60,000 |
| บิดามารดา (อายุ >= 60, รายได้ < 30k/ปี) | 30,000/คน |

### กำหนดการยื่น
- ภ.ง.ด.90/91: ยื่นภายใน **มีนาคม ปีถัดไป** (online ขยาย +8 สัปดาห์)
- ยื่นก่อน = ดีกว่า ห้ามลืม

## 2. Tax-Saving Investment Rules

### Retirement Pool (รวมกัน <= 500,000 THB/ปี)
- RMF: max 30% ของรายได้, cap 500k
- SSF: max 30% ของรายได้, cap 200k (ถือ >= 10 ปีปฏิทิน)
- ประกันบำนาญ: max 15%, cap 200k
- PVD / กบข.: max 15%, cap 500k

### Thai ESG (แยกออกมา <= 300,000 THB/ปี)
- ถือ >= 5 ปีปฏิทิน (นับตามปีก่อนและหลัง)
- ขายก่อนกำหนด = ต้องคืนภาษีพร้อมเบี้ยปรับ 1.5%/เดือน

### ประกันชีวิตทั่วไป
- <= 100,000 THB/ปี
- ประกันสุขภาพ <= 25,000 (รวมในกรอบ 100k)

### บริจาค (e-Donation)
- ด้านการศึกษา/กีฬา/โรงพยาบาลรัฐ = 2x จำนวนจริง, cap 10% ของรายได้สุทธิ

---

## 3. Dividend & Withholding Tax Rules

### เงินปันผล
- หัก ณ ที่จ่าย 10% ทุกครั้ง
- คำนวณทุกปีว่า: **รวมยื่น + ขอเครดิตคืน** vs **ใช้ 10% เป็น Final Tax**
- ถ้า marginal rate < corporate tax rate ของบริษัทผู้จ่าย -> รวมยื่นดีกว่า (ได้คืน)
- ถ้า marginal rate สูง -> Final Tax ที่ 10% ดีกว่า

### ดอกเบี้ยเงินฝาก
- หัก ณ ที่จ่าย 15% (Final Tax)
- ไม่ต้องนำรวมยื่นปลายปี

---

## 4. Corporate Structure Rule (เมื่อไหรควรตั้งบริษัท)

**Trigger:** Net Income ส่วนตัว > 1,000,000 THB/ปี

SME Tax (ทุน <= 5M, รายได้ <= 30M):
```
กำไรสุทธิ 0 - 300,000       = 0%
กำไรสุทธิ 300,001 - 3,000,000 = 15%
กำไรสุทธิ > 3,000,000        = 20%
```
เทียบกับ Personal 35% -> ประหยัดได้มหาศาล

### Income Type Optimization (ก่อนตั้งบริษัท)
- รายได้มาตรา 40(1) เงินเดือน: หักได้ 50% cap 100k — ไม่คุ้ม
- รายได้มาตรา 40(6) วิชาชีพ: หักได้ 30-60%
- รายได้มาตรา 40(7)/(8) รับจ้าง/ธุรกิจ: หักได้ 60% flat — ดีที่สุด

## 5. Banking Structure Rules

### บัญชีธนาคาร (ต้องแยกให้ชัด)
| บัญชี | วัตถุประสงค์ | ธนาคารแนะนำ |
|-------|-------------|-------------|
| Operating | รับเงินเดือน/รายได้หลัก | กสิกร / SCB |
| Investment | ซื้อขายหุ้น DW Crypto | Brokerage (กสิกร/Settrade) |
| Emergency Fund | ฉุกเฉินเท่านั้น | ออมทรัพย์ดอกเบี้ยสูง (KBANK/TTB MAX) |
| Business (ถ้ามีบริษัท) | แยกออกจากส่วนตัวเสมอ | บัญชีนิติบุคคล |

### Emergency Fund Rule
- ต้องมี **>= 6 เดือนของค่าใช้จ่ายรายเดือน** ก่อนลงทุนทุกอย่าง
- ห้ามนำเงินฉุกเฉินไปเป็น Margin หรือ Trading Capital เด็ดขาด
- รูปแบบ: เงินฝากออมทรัพย์สภาพคล่องสูง (ไม่ใช่ Fixed Deposit)

---

## 6. Investment Rules

### Position Sizing
- Single trade/asset: ห้ามเกิน **5% ของ Net Worth**
- Speculative assets (Crypto, DW, Futures): ห้ามเกิน **10% รวม** ของพอร์ต
- ไม่มี Emergency Fund ครบ -> ห้ามเปิด position ใหม่

### Asset Allocation (ลำดับความสำคัญ)
```
1. Emergency Fund (6 เดือน)
2. ชำระหนี้ดอกเบี้ยสูง (> 7% ต่อปี)
3. Tax-saving investments (RMF/SSF/ESG)
4. Core Portfolio (หุ้น/Bond/REITs)
5. Speculative (DW/Crypto/Forex) <- ห้ามแตะถ้า 1-4 ยังไม่ครบ
```

### Stop Loss Rules
- หุ้นรายตัว: -10% to -15% จากราคาซื้อ
- DW: ห้ามถือข้ามคืนเกิน 1-2 วัน โดยไม่มี hedge
- Crypto: -20% hard stop ทุก position

---

## 7. Debt Rules

### หนี้ที่ยอมรับได้
- ดอกเบี้ย < ผลตอบแทนที่คาดหวัง (พร้อม Margin of Safety)
- หนี้บ้าน (MLR-based): OK ถ้า DSR <= 40% ของรายได้
- หนี้บัตรเครดิต (18-28%): ต้องชำระเต็มทุกเดือน ห้ามจ่ายขั้นต่ำ

### หนี้ที่ห้ามทำเด็ดขาด
- กู้เพื่อซื้อ Crypto / DW / หุ้นเก็งกำไร
- Non-bank เงินกู้นอกระบบ
- Leverage > 3x บนสินทรัพย์ที่ผันผวน

---

## 8. Crypto-Specific Rules (ในไทย)

### Tax
- กำไรจาก Crypto = เงินได้มาตรา 40(4)(ฉ) -> หัก 15% ณ ที่จ่าย (บน exchange ไทย)
- ขาดทุนจากเหรียญ A ไป offset กำไรเหรียญ B ได้ -> ต้องซื้อขายบน exchange ที่ SEC license
- Exchange ต่างประเทศ (Binance ทั่วไป): ขาดทุน offset ไม่ได้, VAT ไม่ยกเว้น

### Exchange Rule
- ใช้ exchange ไทย (Bitkub, Orbix, Satang Pro) เป็นหลักเพื่อสิทธิ์ภาษี
- ห้ามโอนไปนอกระบบโดยไม่บันทึก cost basis

---

## 9. Foreign Income Rules (ป.161/2566)

| สถานการณ์ | ผลภาษี |
|----------|--------|
| อยู่ไทย >= 180 วัน + นำเงินเข้าปีเดียวกัน | ต้องยื่น PIT |
| อยู่ไทย >= 180 วัน + เก็บไว้ต่างประเทศ | ยังไม่ต้องยื่น |
| อยู่ไทย < 180 วัน | ไม่ต้องยื่น (แหล่งต่างประเทศ) |
| เงินต้นที่ได้มาก่อน 1 ม.ค. 2567 | ยกเว้น (ป.162/2566) |

**กฎทอง:** แยกบัญชีต่างประเทศให้ชัดระหว่าง "ต้นทุน" กับ "กำไร" ห้ามปนกัน

## 10. Red Flags — ห้ามทำ

- ปลอมใบกำกับภาษี / ประกาศรายได้ต่ำกว่าจริง = อาญา
- นำบัญชีผู้อื่นรับเงินเพื่อเลี่ยงภาษี = ผิด พ.ร.บ. ฟอกเงิน
- ลงทุนกับโครงการ Ponzi ที่การันตีผลตอบแทนตาย = เงินต้นหาย 100%
- ซื้อ Financial Product โดยไม่เข้าใจ = ห้าม

## Pitfalls

- **RMF:** ต้องซื้อทุก 2 ปี ถ้าข้ามปีติดกัน -> ถูกประเมินย้อนหลัง
- **SSF/ESG ขายก่อนกำหนด:** เบี้ยปรับ 1.5%/เดือน ย้อนตั้งแต่ปีที่ใช้ลดหย่อน
- **เงินปันผล:** คำนวณก่อนทุกปีว่า Final Tax 10% หรือรวมยื่นคุ้มกว่า
- **Crypto offshore:** loss ไม่ได้ offset = เสียเปรียบมาก

## Quick Reference Checklist (รายปี)

```
[ ] Emergency fund >= 6 เดือน
[ ] หนี้บัตรเครดิต = 0
[ ] คำนวณ Tax bracket ปีนี้ก่อนสิ้นปี
[ ] เติม RMF/SSF/ESG ให้เต็ม cap ก่อน 31 ธ.ค.
[ ] คำนวณ Dividend: Final Tax vs รวมยื่น
[ ] ตรวจ foreign income ที่นำเข้าไทย
[ ] ยื่น ภ.ง.ด. ก่อน 31 มี.ค. (หรือ +8wks online)
[ ] ประเมิน: ถึงเวลาตั้งบริษัทหรือยัง (net income > 1M?)
```
