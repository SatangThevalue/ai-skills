# พื้นฐานตลาด Forex และค่าธรรมเนียมการเทรด

สกิลนี้รวบรวมคำศัพท์และแนวคิดพื้นฐานในตลาด Forex เพื่อใช้เป็นแหล่งอ้างอิงในการเทรดและพัฒนาระบบเทรดอัตโนมัติ (EA/Trading Bot) 

## 1. หมวดหมู่ของคู่เงิน (Currency Pairs)
การซื้อขาย Forex จะทำเป็นคู่เสมอ โดยประกอบด้วย **Base Currency (สกุลเงินหลัก)** อยู่ด้านหน้า และ **Quote Currency (สกุลเงินอ้างอิง)** อยู่ด้านหลัง (ตัวอย่าง: `EUR/USD` -> Base=EUR, Quote=USD)

### 1.1 คู่เงินหลัก (Major Currency Pairs)
คู่เงินที่มี **ดอลลาร์สหรัฐ (USD)** เป็นส่วนประกอบ มีสภาพคล่อง (Liquidity) สูงที่สุดในตลาด ความผันผวนเสถียร และมีค่า Spread ต่ำที่สุด เหมาะกับกลยุทธ์ส่วนใหญ่และระบบเทรดอัตโนมัติ
* **ตัวอย่างหลัก:** EUR/USD, GBP/USD, USD/JPY, USD/CHF, AUD/USD, NZD/USD, USD/CAD

### 1.2 คู่เงินรอง (Minor Currency Pairs / Cross Pairs)
คู่เงินที่ **ไม่มี USD** เป็นส่วนประกอบ แต่เป็นการจับคู่กันเองระหว่างสกุลเงินหลักอื่นๆ สภาพคล่องจะน้อยกว่า Majors เล็กน้อย และ Spread มักจะกว้างกว่า บางคู่เงินจะมีความผันผวนสูงมาก เช่น ตระกูล JPY-Cross
* **ตัวอย่างหลัก:** EUR/GBP, GBP/JPY, EUR/JPY, AUD/CAD, CHF/JPY, GBP/AUD

### 1.3 คู่เงินแปลกใหม่ (Exotic Pairs)
คู่เงินของประเทศเศรษฐกิจเกิดใหม่ (Emerging Markets) จับคู่กับ USD สภาพคล่องต่ำ Spread กว้างมาก ไม่เหมาะกับกลยุทธ์ Scalping
* **ตัวอย่าง:** USD/THB (ดอลลาร์/บาท), USD/ZAR, USD/MXN

## 2. ต้นทุนและค่าธรรมเนียมในการเทรด (Trading Costs & Fees)

### 2.1 สเปรด (Spread)
Spread คือ **ส่วนต่างระหว่างราคาเสนอซื้อ (Ask) และราคาเสนอขาย (Bid)** 
* ถือเป็นรายได้หลักของโบรกเกอร์ (ในบัญชีประเภท Standard)
* **สูตร:** `Spread = Ask Price - Bid Price`
* มีทั้งแบบคงที่ (Fixed Spread) และลอยตัว (Floating/Dynamic Spread) ซึ่งในตลาดจริงส่วนใหญ่เป็นแบบลอยตัว

### 2.2 ค่าคอมมิชชั่น (Commission)
ค่าธรรมเนียมคงที่ ที่โบรกเกอร์เรียกเก็บจากการเปิด/ปิดออเดอร์ มักคิดเป็น "ดอลลาร์ต่อปริมาณ 1 Lot"
* มักพบในบัญชีประเภท **ECN (Electronic Communication Network) หรือ Raw Spread** (บัญชีเหล่านี้ค่า Spread จะเข้าใกล้ 0 แต่โบรกเกอร์จะเก็บค่าต๋งผ่านคอมมิชชั่นแทน)

### 2.3 ค่าธรรมเนียมข้ามคืน (Swap / Rollover)
คือ ดอกเบี้ยที่เกิดจากส่วนต่างของอัตราดอกเบี้ยนโยบายของ 2 สกุลเงินในคู่ที่เราเทรด
* มี 2 ฝั่งคือ **Swap Long (Buy)** และ **Swap Short (Sell)**
* อาจมีค่าเป็น **บวก (ได้เงินเพิ่มเข้าพอร์ต)** หรือ **ลบ (โดนหักเงินจากพอร์ต)** หากถือออเดอร์ข้ามข้ามคืนเวลา Server
* วันพุธข้ามไปวันพฤหัสบดี (หรือขึ้นกับแต่ละโบรกเกอร์) มักจะมีการคิดค่า Swap คูณ 3 (Triple Swap) เพื่อชดเชยวันหยุดเสาร์-อาทิตย์
* **Swap Free (Islamic Account):** บัญชีที่ไม่มีการคิดค่า Swap เหมาะสำหรับคนที่ถือรันเทรนด์ระยะยาว

## 3. ข้อพิจารณาสำหรับการพัฒนาระบบเทรด (Algorithmic Trading / Survival-First)

สำหรับนักพัฒนาระบบเทรดอัตโนมัติ (Quant / Bot Developer) ต้องพิจารณาตัวแปรค่าธรรมเนียมเหล่านี้ใน Logic เสมอเพื่อปกป้อง Drawdown:

1. **Spread Filter / Slippage Protection:**
   * EA ต้องมีฟังก์ชันเช็ค Spread แบบ Real-time และงดเปิดออเดอร์หาก `Current_Spread > Max_Allowed_Spread` (เพื่อป้องกันการได้ราคาที่แย่จากภาวะ Spread ถ่างช่วงข่าว Non-farm หรือช่วงตลาดเปิดข้ามวัน)
2. **True Cost Position Sizing:**
   * ในการคำนวณ Position Size ด้วย Risk % ต้องบวกต้นทุนของ Commission และความกว้างของ Spread เข้าไปในระยะ Stop Loss เสมอ หากไม่บวกเข้าไประบบอาจเสี่ยงขาดทุนมากกว่า % Risk ที่ตั้งไว้
3. **Swap Decay in Long-Term Holds:**
   * หากพัฒนาระบบ Trend Following ที่ถือออเดอร์ยาวเป็นสัปดาห์หรือเป็นเดือน ต้องทำ Backtest โดยเปิดโหมดคิดค่า Swap เสมอ เนื่องจาก Swap ลบสะสม อาจเปลี่ยนกลยุทธ์ที่กำไรเป็นขาดทุนได้ (หรือควรเลือกใช้บัญชีประเภท Swap-Free ในการรันจริง)
4. **Bid vs Ask Pricing Logic:**
   * คำสั่ง `Buy` ถูก Match ที่ราคา `Ask` และปิดที่ `Bid`
   * คำสั่ง `Sell` ถูก Match ที่ราคา `Bid` และปิดที่ `Ask`
   * การเช็คเงื่อนไข Indicator ทะลุแนวรับแนวต้าน ต้องเลือกใช้ราคาให้ถูกฝั่งเสมอ
