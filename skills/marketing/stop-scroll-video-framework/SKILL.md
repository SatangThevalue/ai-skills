# Stop-Scroll Video Framework (สไตล์แมนหยุดนิ้ว)

สถาปัตยกรรมและกรอบการสร้างคลิปวิดีโอสั้นแนวคิด **"หยุดนิ้ว (Stop Scrolling)"** ที่เน้นความหนาแน่นของคุณค่าต่อวินาที (Value Density) สูงสุด คลิปยาวเพียง 15–30 วินาที เพื่อดันอัตราการดูจบ (Completion Rate > 90%) และส่งสัญญาณบวกแก่อัลกอริทึม Facebook Reels / TikTok

---

## 1. การจำแนก 4 รูปแบบคอนเทนต์หยุดนิ้ว (Content Archetypes)

จากการถอดรหัสคลิปต้นแบบ สกัดออกมาได้ 4 รูปแบบหลัก:

| รูปแบบคอนเทนต์ | แกนความคิด (Core Concept) | โครงสร้างสคริปต์ | ตัวอย่างการเปิด (Hook) |
|---|---|---|---|
| **1. Contrast Polarizer (เปรียบเทียบขั้วตรงข้าม)** | วางสิ่งที่ตรงข้ามกันชัดเจนเพื่อกระตุ้นให้สมองคนดูหยุดเปรียบเทียบทันที | `[ขั้ว A ที่แย่] VS [ขั้ว B ที่ดี] → ฟันธงข้อเท็จจริง → สรุปสาระสำคัญ` | "วิดีโอ 1 นาทีที่น่าเบื่อ กับวิดีโอ 1 ชั่วโมงที่โคตรน่าสนใจ คุณว่าคนจะเลือกดูอันไหน?" |
| **2. Myth Buster (หักล้างความเชื่อผิด)** | ท้าทายความเชื่อเดิมที่คนส่วนใหญ่คิดว่าถูก แล้วเฉลยข้อเท็จจริง | `[ความเชื่อที่ผิด] → "แต่ความจริงคือ..." → [เหตุผลแท้จริง]` | "คิดว่าคลิปสั้นต้องทำแค่ 10 วิถึงจะไวรัล? ผิดสนิทครับ ความจริงคือ..." |
| **3. Micro-Actionable (สูตรแก้ปัญหา 15 วิ)** | 1 ปัญหาหนักอก + 1 วิธีแก้ตรงจุด ไม่เวิ่นเว้อ ไม่ขายของยืดยาว | `[ปัญหาคนดู] → [สูตรแก้ 1 ข้อ] → [ผลลัพธ์ทันที]` | "คนเลื่อนผ่านคลิปคุณใน 2 วิแรก แก้ด้วย 1 เทคนิคนี้..." |
| **4. Psychological Truth (จิตวิทยากระตุกคิด)** | อธิบายพฤติกรรมมนุษย์ที่คนดูรู้สึกร่วมแต่ไม่เคยพูดออกมา | `[พฤติกรรมที่เกิดขึ้นจริง] → [กลไกจิตวิทยา] → [บทเรียน]` | "ทำไมคนถึงยอมจ่ายเงิน 3,000 ซื้อสิ่งที่ไม่ได้ใช้ แต่บ่นหนังสือ 300 แพง?" |

## 2. โครงสร้างเวลาของคลิป (Script Pacing & Anatomy)

ความยาวที่สมบูรณ์แบบคือ **12 – 25 วินาที** (ไม่เกิน 60–80 คำพูดภาษาไทย):

```text
[0:00 - 0:03] HOOK: Contrast Question / หักล้างทันที (หยุดนิ้วโป้ง)
      ↓
[0:03 - 0:07] CLARITY: ฟันธงคำตอบตรงประเด็น (สมองได้รับรางวัลทันที)
      ↓
[0:07 - 0:15] CORE VALUE: สรุปบทเรียน / การนำไปปรับใช้ (Actionable Insight)
      ↓
[0:15 - 0:18] MEMORABLE PUNCHLINE: ประโยคปิดคลิปคมๆ (ไม่มี CTA ไร้สาระ)
```

## 3. สถาปัตยกรรมด้านภาพและเสียง (Production Blueprint)

### 3.1 การตัดต่อ (Visual & Editing)
- **Jump Cut Pacing:** ตัดสลับระยะภาพ (Scale 1.0x สลับ 1.15x Punch-in) ทุกๆ 1 ประโยค หรือทุก 2–3 วินาที เพื่อรีเซ็ตความสนใจของสายตา
- **Framing:** กึ่งกลางจอ (Center-aligned), Eye-level ระดับสายตา, ฉากหลังละลายเล็กน้อย (Shallow depth of field)
- **Color Theme:** โทนอบอุ่นตัดเย็น (Warm key light + Cool rim light) สะท้อนความน่าเชื่อถือ

### 3.2 ตัวอักษรและซับไตเติล (Kinetic Typography)
- **ฟอนต์:** Sans-serif ภาษาไทยโมเดิร์น ไร้หัว หนาชัดเจน (เช่น Sarabun Bold, Kanit Bold)
- **Color Coding:** 
  - ข้อความหลัก: สีขาวบริสุทธิ์ (`#FFFFFF`) พร้อมขอบเงาบาง
  - คำเน้น (Keywords): สีเหลืองส้ม (`#FFCC00` หรือ `#FF7A00`)
- **เรนเดอร์ข้อความ:** ห้ามใช้ `drawtext` ของ FFmpeg ตรงๆ เพราะสระภาษาไทยจะซ้อนทับ/ลอย ให้เรนเดอร์ผ่าน Python `Pillow (PIL)` เป็นภาพ Overlay PNG โปร่งใสเสมอ

### 3.3 เสียงและดนตรี (Audio Architecture)
- **TTS Voice:** เสียงพูดไทยหนักแน่น มั่นใจ (แนะนำ `th-TH-NiwatNeural` หรือ `th-TH-PremwadeeNeural`)
- **Audio Ducking:** ดนตรีพื้นหลัง (Modern Lo-fi / Tech Beat) ต้องลดระดับเสียงลง 70-80% เมื่อมีเสียงพากย์
- **Sound Effects (SFX):** ใส่เสียง Whoosh / Pop สั้นๆ ตรงกับจังหวะที่ Keyword เด้งขึ้นมา

## 4. Prompt Template สำหรับ 9Router (สร้างสคริปต์ 4 รูปแบบ)

```python
PROMPT_TEMPLATE = """
คุณคือผู้เชี่ยวชาญการเขียนสคริปต์วิดีโอสั้นสไตล์ "หยุดนิ้ว" สำหรับ Facebook Reels และ TikTok
จงแต่งสคริปต์ภาษาไทย ความยาว 15-20 วินาที (ไม่เกิน 70 คำ) 
หัวข้อ: {topic}
รูปแบบ: {archetype} (1: Contrast, 2: Myth Buster, 3: Micro-Actionable, 4: Psychological Truth)

โครงสร้างบังคับ:
1. Hook (0-3 วินาทีแรก): คำถามเปรียบเทียบหรือประโยคหักล้าง
2. Core (3-8 วินาที): ฟันธงเฉลยทันที
3. Takeaway (8-15 วินาที): บทเรียนสั้นที่เอาไปใช้ได้ทันที
4. Punchline: คำคมปิดท้าย 1 ประโยค

ส่งผลลัพธ์เป็น JSON รูปแบบนี้เท่านั้น:
{{
  "hook": "...",
  "core": "...",
  "takeaway": "...",
  "punchline": "...",
  "full_transcript": "...",
  "highlight_words": ["คำที่ต้องเน้นสีส้ม", "..."]
}}
"""
```

## 5. การประยุกต์ใช้กับระบบ Auto-Pin Comment

เนื่องจากเนื้อหาวิดีโอสั้นและกระชับมาก ห้ามใส่การขายสินค้าลงในเนื้อหาคลิปโดยเด็ดขาด:
1. ปล่อยให้คลิปทำหน้าที่ **"ดึงดูดสายตาและสะสมยอดวิว"**
2. นำสินค้าหรือบริการที่เกี่ยวข้องกับหัวข้อไปวางไว้ที่ **"คอมเมนต์แรก (Auto-Pin Comment)"**
3. เขียนแคปชันสั้น 1 บรรทัด: `"สนใจแนวคิดเพิ่มเติม ดูรายละเอียดในคอมเมนต์แรก👇"`
